Genesis Кодекс+

Законодательство ПМР офлайн

Genesis Кодекс+ — приложение для Android с полным текстом действующих кодексов и законов Приднестровской Молдавской Республики. Вся база хранится на устройстве и открывается без подключения к интернету — подходит для юристов, предпринимателей, госслужащих и всех, кому нужен быстрый доступ к тексту закона.

Как установить

  1. Скачайте APK-файл, нажав кнопку «Скачать APK» в начале страницы.
  2. Откройте скачанный файл — через панель уведомлений браузера или через приложение «Файлы».
  3. Если система запросит разрешение на установку из неизвестных источников — разрешите его для браузера или файлового менеджера, которым вы открываете файл (обычно: Настройки → Приложения → Особый доступ → Установка неизвестных приложений).
  4. Google Play Protect может показать предупреждение о том, что приложение не проверено. Это стандартное предупреждение для любых APK, установленных не из Google Play, а не признак того, что конкретно это приложение опасно. Нажмите «Всё равно установить».
  5. Дождитесь завершения установки.
  6. Запустите Genesis Кодекс+ с главного экрана. При первом запуске приложение распакует базу актов — это может занять до минуты.

Для официального использования — в суде, органах власти, при подаче документов — руководствуйтесь текстами, опубликованными в Сборнике актов законодательства ПМР (САЗ) и на официальных ресурсах органов государственной власти ПМР.
